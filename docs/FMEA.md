# Registro FMEA — modi di guasto e controlli

Ogni riga è collegata ad almeno un test negativo. `tests/test_fmea.py` verifica che **ogni** test
citato esista: se un test viene rimosso o rinominato la build fallisce (controllo bloccante).

Scala: S = severità (1-5), O = occorrenza stimata (1-5), D = difficoltà di rilevazione (1-5).
RPN = S×O×D è indicativo: serve a ordinare, non a dichiarare il rischio "accettabile".
